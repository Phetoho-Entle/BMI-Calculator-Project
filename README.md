BMI Calculator (Python)


This project is a simple Body Mass Index (BMI) Calculator developed using Python. The application allows users to enter their height and weight and calculates their BMI based on standard health guidelines.

The project was created as part of my Python learning journey and helped me build a foundation in programming concepts such as user input, variables, data types, calculations, conditional statements, and output formatting.

Features
User-friendly input prompts
BMI calculation based on height and weight
BMI category classification
Instant results and feedback
